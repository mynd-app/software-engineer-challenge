# PR #42: Add data export for privacy requests

**Author:** Sam (backend) - **Base:** `main` - **Status:** review requested from you

## Description

Under the Privacy Act, people can ask for a copy of the personal information we hold about them.
At the moment we do this by hand, which takes a while. This adds an endpoint that builds a CSV of
a user's check-ins and returns a download link, so support (and later the app) can do it in one
call.

- `GET /api/users/{user}/export` builds the CSV and returns `{"data":{"url": "..."}}`
- Stores the file so the link keeps working if the user wants to download it again later
- Logs the export so we have an audit trail
- Test included

Tested locally with the seeded users, works well. Would be great to get this in this week, as we
have two requests waiting.

+<?php
+
+namespace App\Http\Controllers\Api;
+
+use App\Http\Controllers\Controller;
+use App\Models\User;
+use Illuminate\Http\JsonResponse;
+use Illuminate\Support\Facades\Log;
+use Illuminate\Support\Facades\Storage;
+
+class DataExportController extends Controller
+{
+    public function __invoke(User $user): JsonResponse
+    {
+        $rows = [['date', 'mood', 'intensity', 'note']];
+
+        foreach ($user->checkIns()->oldest()->get() as $checkIn) {
+            $rows[] = [
+                $checkIn->created_at->toDateTimeString(),
+                $checkIn->mood->value,
+                $checkIn->intensity,
+                $checkIn->note,
+            ];
+        }
+
+        $csv = collect($rows)
+            ->map(fn (array $row) => implode(',', array_map(
+                fn ($value) => '"'.str_replace('"', '""', (string) $value).'"',
+                $row,
+            )))
+            ->implode("\n");
+
+        $path = "exports/{$user->id}.csv";
+
+        Storage::put($path, $csv);
+
+        Log::info('Data export generated', [
+            'user_id' => $user->id,
+            'email' => $user->email,
+            'csv' => $csv,
+        ]);
+
+        return response()->json(['data' => ['url' => Storage::url($path)]]);
+    }
+}
